# Jeel – AI Use Log

## AI Tools Used

| Stage | AI Tool | Purpose | AI Contribution and Team Involvement |
|---|---|---|---|
| Stage 1 | ChatGPT | Figma Prompt Preparation | Assisted in preparing prompts for generating UI designs based on project requirements. |
| Stage 2 | Gemini | Jetpack Compose Screen Generation | Generated UI screen code using AI prompts and Figma design references. The team reviewed the generated screens and checked design consistency, navigation, and available interactions. |
| Stage 2 | Gemini | Error Handling and Troubleshooting | Helped identify Android Studio errors, explain their causes, and suggest possible solutions. |
| Stage 2 | ChatGPT | GitHub Setup and Collaboration | Provided guidance on connecting the project to GitHub, cloning the repository, and coordinating team contributions. |
| Stage 2 | ChatGPT | Milestone 2 Report Review | Assisted in checking the report against submission requirements and identifying missing or incomplete sections. |

## Team Responsibility

AI was used as a development support tool. Team members were responsible for reviewing generated interfaces, checking screen navigation, examining available UI interactions, and making final decisions.

The current implementation focuses on UI prototyping and navigation. Backend authentication, persistent data storage, and live booking services are not claimed as implemented.
