# Jeel — UI prototype

This project contains screen design and page navigation only. Each screen has its own Kotlin file under `ui/screens`, with a Compose preview.

Form fields, selections and tabs are temporary visual interactions. Booking, authentication, saving, requests, reviews, search and data storage are not implemented. Sample content remains static. Business logic can be added in the next phase.

Open MyApplication2 in Android Studio, wait for Gradle sync, select a device and press Run. Choose a role to browse its screens.
