# Jeel — Experience & Mentorship Platform

## About the Project

Jeel is an Android mobile application designed to connect students and young professionals with experienced and retired professionals to support knowledge sharing, mentorship, and career development.

The platform helps younger generations receive practical guidance while allowing experienced individuals to share their knowledge and expertise.

## Target Users

- **Mentors:** Experienced and retired professionals willing to share their knowledge.
- **Mentees:** University students, graduates, and young professionals seeking guidance.

## Core Features

- User Registration and Login
- Mentor and Mentee Profiles
- Mentor Search and Matching
- Mentorship Requests
- Session Booking and Management
- Challenge Submission
- Action Plan and Progress Tracking
- Ratings and Feedback
- Notifications

## Technology Stack

- **Language:** Kotlin
- **UI Framework:** Jetpack Compose
- **IDE:** Android Studio
- **Version Control:** Git and GitHub
- **Backend / Database:** To be determined

## System Architecture

Jeel is planned to follow the **MVVM (Model–View–ViewModel)** architecture, separating the user interface, application logic, and data management.

- **UI Layer:** Jetpack Compose screens and components.
- **ViewModel Layer:** UI state and application logic.
- **Repository Layer:** Data access and communication.
- **Data Layer:** Local or remote data sources.

Architecture Diagram: `docs/architecture.png` (planned).

## Planned Jetpack Components

- **Navigation Compose:** Screen navigation.
- **ViewModel:** UI state management.
- **StateFlow:** Reactive state updates.
- **Room / DataStore:** Local storage and user preferences, if needed.
